# Классификатор обращений

Небольшой Python-скрипт для классификации обращений пользователей.

## Что делает программа

Программа читает 5 сообщений из файла `messages.txt`.

Для каждого сообщения определяется категория:

- справка
- жалоба
- другое

Также программа выводит черновик ответа на русском языке.

## Как запустить

Необходимо установить Python 3.

Запуск программы:

```bash
python main.py
